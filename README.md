FF Fan Studio

Photo souvenir fan creation system for tourism and local events.

Overview

FF Fan Studio is a web application that allows visitors to create personalized souvenir fans using their own photos.

Users can:

Take a photo or select one from their device
Adjust position, size, and rotation
Preview the final fan design
Submit an order
Receive the finished fan at the pickup counter
Project Status

Currently under development.

Planned features:

Firebase Queue System
WAIT / PRINTING / READY status display
Pickup management
Multilingual support
Tourism event operation support
